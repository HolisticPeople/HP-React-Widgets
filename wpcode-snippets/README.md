# HP React Widgets - WPCode Snippets

This folder contains optional WPCode snippets that extend HP React Widgets.

The retired ThemeHigh address integration snippet has been removed. New
address-book integrations use the HP Core-owned `hp-address-book` contract.

The remaining `fluentcrm-create-order.php` file is unrelated to HP Address
Book and remains outside this retirement change.
